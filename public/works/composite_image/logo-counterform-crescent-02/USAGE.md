# 规范用法 · 屿汐鲜运（`logo-counterform-crescent-02`）

风格：负形反切（`logo-counterform-crescent`）｜标志类型：图形标｜构成：负空间
画布 800 × 940，圆盘直径 500。

## 最小尺寸

| 场合 | 圆盘直径 | 说明 |
|---|---|---|
| 印刷 | **≥ 10 mm** | 再小那道横向窄切口会消失，一弯退化成一整块 |
| 屏幕 | **≥ 40 px** | 同上 |
| 整幅偏心竖向锁定（含竖排商号与副名） | 印刷 ≥ 16 mm 宽 ／ 屏幕 ≥ 64 px 宽 | 低于此只用圆盘，去掉文字 |

**注意**：图形标未经使用积累不具备独立识别力。**长期只用圆盘不带商号是不被允许的**，
小尺寸去掉文字只针对图标、favicon 这类确实放不下的位置。

## 单色版

主色换成单一墨色、底与反切件换成纸白即成立。
**单色版与彩色版逐形相同**（本机实测），因为三道反切件用的就是底色 token 本身。

> 这一条同时是检验方法：如果哪一天有人改了这份 svg，把某道反切件换成了
> 「另一个浅色」，单色版会当场塌成一坨实心。**发版前跑一次单色版就能抓到。**

```bash
node docs/design-guides/composite_image/logo/_tools/logo-proof.mjs \
  mono logo-counterform-crescent-02.svg vec.white out.png
```

## 留白

- 圆盘外圈至少留出**半个圆盘半径**（= 直径的 1/4）的空场。
- 竖排商号与圆盘之间的间距不少于**一个字身**。
- 留白区内不放任何其他元素。

## 不可做

- 不许在圆盘上压字——压上去就成了叠印字图组合，是另一条轴上的取值。
- 不许把竖排商号改成横排，那是另一个锁定方式。
- 不许镜像翻转（一弯的开口方向是这个标志的一部分）。
- 不许在负形里放第二个实心占位件。
- 不许给圆盘加渐变、纹理、外描边、投影或半透明。
