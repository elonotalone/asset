# 规范用法 · 叁两茶事（`logo-seal-grid-03`）

风格：方印格（`logo-seal-grid`）｜标志类型：徽章｜构成：印章
画布 840 × 840，印面 600 × 600，印床四等分，格边 264。

## 最小尺寸

| 场合 | 印面边长 | 说明 |
|---|---|---|
| 印刷 | **≥ 14 mm** | 再小四个字连成一片，缺角也看不见 |
| 屏幕 | **≥ 56 px** | 同上 |
| 罗马商号 | **印面 < 14 mm 时一律去掉** | 只留印面，那是本件的小尺寸版本，不是残缺版 |

## 单色版

印色换成单一墨色即成立，阴阳关系不变：阳文格仍是实心底、字取纸白，
阴文格仍是空底、字取墨色。**单色版与彩色版逐形相同**（本机实测）。

印色本身可以换（朱、藏蓝、松绿都成立），但**换印色不产生新的标志**——换了色还是这一枚印。

```bash
node docs/design-guides/composite_image/logo/_tools/logo-proof.mjs \
  mono logo-seal-grid-03.svg vec.surface out.png
```

## 留白

- 印面四周至少留出**一个格宽**（= 印面边长的 0.44）的空场。
- 留白区内不许放边框、圆角卡片底、第二枚印。
- 罗马商号与印面下沿之间固定一个 1/8 印面边长的间距，不许贴紧也不许拉开。

## 四字读序

**右上「叁」→ 右下「两」→ 左上「茶」→ 左下「事」。** 这是印文的读法，
不是横排的从左到右。因为这个，四个字在 svg 里标成装饰件，
整枚印的可访问名由根节点承担——屏幕阅读器按 DOM 序逐字念会念错。

## 不可做

- 不许旋转（印是正的），不许镜像。
- 不许只取其中两格，或改成 1×4、3×1 等其他分格。
- 不许把罗马商号挪到印面右侧——那会变成横向锁定，属另一个风格。
- 不许做旧：斑驳、飞白、纸纹、印泥不均、投影，一律不行。
- 不许四个字不等大，或某个字加粗、变色以示重点。
- 不许把边栏做成圆角边框（印格自身的圆角是全篇一致的比例，与此无关）。
