# 规范用法 · 泓远港运 HY（`logo-grid-monogram-01`）

风格：模数切分字组（`logo-grid-monogram`）｜标志类型：缩写字母组｜构成：几何切分
画布 1120 × 560，模数 56，字组方场 392 × 336（七列六行）。

## 最小尺寸

| 场合 | 字组方场短边 | 说明 |
|---|---|---|
| 印刷 | **≥ 12 mm** | 再小沟槽会糊在一起，H 与 Y 读不出来 |
| 屏幕 | **≥ 48 px** | 同上；48 px 时一个模数只有 8 px |
| 整幅横向锁定（含商号与副名） | 印刷 ≥ 34 mm 宽 ／ 屏幕 ≥ 136 px 宽 | 低于此只用字组方场，去掉右侧文字 |

## 单色版

**单色版是本件的默认交付形态。** 底场换成纸白、字组与文字换成单一墨色即成立，
形一个不变（本机实测：单色版与彩色版逐形相同）。深浅可以互换，互换后仍是同一个标志。

复现：

```bash
node docs/design-guides/composite_image/logo/_tools/logo-proof.mjs \
  mono logo-grid-monogram-01.svg vec.ink out.png
```

## 留白

- 字组方场四周至少留出**一个模数**（= 方场短边的 1/6）的空场。
- 商号右侧的留白不少于**两个模数**。
- 留白区内不许放任何其他元素：其他标志、二维码、边框、口号，一律不行。

## 不可做

- 不许拉伸变形、不许改变方场的七列六行比例。
- 不许只取字组的一半，或只用 H、只用 Y。
- 不许把商号挪到方场下方——那是另一个锁定方式，属于另一件作品。
- 不许给某一个模块单独加大或去掉圆角（圆角恒为该模块短边的 1/12）。
- 不许在字组里加入第二个图形（箭头、船锚、地球、齿轮）。
